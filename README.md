# Performance Appraisal System – Power BI Dashboard

An interactive Power BI dashboard created using 75 employee responses collected as part of my Performance Appraisal System project.

## Tools Used

- Power BI
- Microsoft Excel
- Data Visualization

## Project Overview

The collected employee responses were transformed into an interactive dashboard to make the data easier to explore, understand and interpret.

## Dashboard Preview

The dashboard provides a visual representation of the collected responses and helps present the findings in a clear and interactive format.

## Key Learning

This project helped me gain practical experience in transforming raw responses into visual insights and creating an interactive Power BI dashboard.
